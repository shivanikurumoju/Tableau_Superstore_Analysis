# Tableau Superstore Sales Analysis

## Project Overview

An interactive sales dashboard built using Tableau Public to analyze sales performance, profitability, customer segments, regional performance, and the relationship between discount and profit using the Sample Superstore dataset.

## Dashboard Preview

![Tableau Superstore Sales Dashboard](Dashboard.png)

## Key KPIs

- Delivery Days: 39,558
- Average Discount: 15.62%
- Profit Margin: 12.33%
- Sales Per Customer: 2,897

## Dashboard Analysis

The dashboard includes:

- Monthly Sales Trend
- Monthly Profit Trend
- Sales by Segment
- Sales by State
- Sales by Region
- Relationship Between Discount and Profit
